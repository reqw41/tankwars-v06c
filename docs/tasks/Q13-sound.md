# Q13. Звук на таймере ВИ53 на ассемблере 8080 (маленькая задача)

Нужно написать ЧЕТЫРЕ подпрограммы в файле `v06c/src/sound.asm`: `snd_tone`, `snd_off`, `snd_play`, `snd_tick`.
Больше никакие файлы менять нельзя.

## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/sound.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  звук:`. Пока печатает `FAIL ...` — не готово: в
сообщении написано, какие записи в порты сделала твоя программа и какие нужны (вид `порт=байт`, шестнадцатеричные).
После зелёного теста запусти ещё `node v06c/test/run.mjs` — он должен закончиться `OK ...`.

## Железо
Таймер ВИ53 Вектора: порт `0x08` — управляющее слово, порт `0x0B` — счётчик канала 0. Запись в порт: `out (0x08), a`.
- Тон: в порт `0x08` байт `0x36` (канал 0, меандр, делитель двумя байтами), затем в порт `0x0B` младший байт делителя
  и следом в тот же порт `0x0B` старший байт.
- Тишина: в порт `0x08` байт `0x36` и больше ничего (счётчик без делителя молчит).

## snd_tone (HL = делитель)
```
out (0x08) <- 0x36;   out (0x0B) <- L;   out (0x0B) <- H
```

## snd_off
```
out (0x08) <- 0x36
```

## Таблица эффекта
Ноты подряд, по 3 байта: делитель (слово, младший байт первым) и длительность в кадрах (байт 1..255).
Конец таблицы — слово 0 (два нулевых байта). Делитель 1 — пауза: вместо тона тишина на указанное число кадров.

## Ячейки (уже есть в файле после метки sound_end)
`snd_ptr` (слово) — адрес следующей ноты; 0 — эффект не играет. `snd_cnt` (байт) — сколько кадров осталось текущей ноте.

## Общая часть «взять следующую ноту» (сделай подпрограммой, например snd_next)
```
D = слово по адресу snd_ptr
если D == 0:     snd_off;  snd_ptr = 0;  выйти                  ; эффект кончился
если D == 1:     snd_off                                         ; пауза
иначе:           snd_tone(D)
snd_cnt = байт по адресу snd_ptr + 2
snd_ptr = snd_ptr + 3
```

## snd_play (HL = адрес таблицы)
```
snd_ptr = HL;  взять следующую ноту (первая нота звучит сразу)
```

## snd_tick (вызывается раз в кадр)
```
если snd_ptr == 0:  выйти (ничего не писать в порты)
snd_cnt = snd_cnt − 1
если snd_cnt != 0:  выйти
взять следующую ноту
```

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`, `out (c),a`.
Нельзя писать `sub (метка)`, `cp (метка)` или `ld e,(метка)` — sjasmplus примет это за число. Значение из ячейки бери
так: `ld a,(метка)`, а слово — `ld hl,(метка)`.
Можно: `out (0x08), a` (только из регистра A и с номером порта числом), `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`,
`ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`, `inc`/`dec`, `cp`, `sub`, `and`, `or`, `xor`,
`push`/`pop`.
Свои метки начинай с `snd_`; новые ячейки данных — после метки `sound_end`.
