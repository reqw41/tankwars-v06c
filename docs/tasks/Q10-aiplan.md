# Q10. Простые планировщики компьютера и запись выстрела на ассемблере 8080 (маленькая задача)

Нужно написать ТРИ подпрограммы в файле `v06c/src/aiplan.asm`: `plan_stupid`, `plan_birdy`, `record_shot`.
Больше никакие файлы менять нельзя.

## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/aiplan.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  планировщики:`. Пока печатает `FAIL ...` — не готово:
в сообщении написано, какая подпрограмма, с какими входами и какие поля не совпали. После зелёного теста запусти ещё
`node v06c/test/aistep.mjs`, `node v06c/test/hud.mjs`, `node v06c/test/run.mjs` — все должны закончиться `OK ...`.

Это перенос функций `planStupid`, `planBirdy`, `firstWeapon`, `recordShot` из `web/tankwars.js` (прочитай их).

## Данные
Игрок на месте i (1..n) — запись `players + (i − 1)·PL_SIZE`; `n_players` — число игроков (байт). Адрес записи по месту
даёт готовая подпрограмма `dt_ptr` (death.asm): вход A = место, выход HL = адрес записи; портит DE.
Поля (`v06c/src/player.inc`):
- `PL_POWER` (слово), `PL_MEN` (слово со знаком), `PL_AMMO + 2·w` (слово со знаком — запас оружия w);
- план: `PL_AI_PLAN` (байт «план готов»), `PL_AI_POWER` (слово со знаком), `PL_AI_ANGLE` (байт), `PL_AI_FACING` (байт: 1
  или 0xFF = −1), `PL_AI_WEAPON` (байт);
- история: `PL_AI_S1` — последний выстрел (4 байта: мощность — слово, x — слово), `PL_AI_S2` — предпоследний (так же).

Случайные числа: `random` (random.asm) — вход DE = n, выход HL = Random(n) от 0 до n − 1; портит AF, BC, DE.
ПОРЯДОК И ЧИСЛО вызовов `random` должны быть точно как ниже — тест сверяет RandSeed.

## plan_stupid (A = место; ячейка ap_rebound = 0 или 1)
```
1. повторять:  r = Random(3)   пока r == 1            ; r = 0 -> направление −1 (0xFF), r = 2 -> направление 1
   PL_AI_FACING = (r == 0) ? 0xFF : 1
2. оружие = 11
   для w = 1, 2, 3, 4 по порядку:  если запас[w] > 0 (слово со знаком, строго больше нуля):  оружие = w
   PL_AI_WEAPON = оружие                               ; то есть последнее из 1..4 с запасом, иначе 11
3. PL_AI_ANGLE = Random(90)
4. мощность = Random(5000) + 20
5. если ap_rebound == 0:
       PL_AI_FACING = (n_players / 2 < место) ? 0xFF : 1     ; деление нацело: 2 -> 1, 3 -> 1, 4 -> 2
       мощность = Random(250) + 50
   (при ap_rebound == 1 пятый шаг пропускается целиком, Random(250) НЕ вызывается)
6. если 10·men < мощность (сравнение СО ЗНАКОМ; men бывает 0 и отрицательным):  мощность = 10·men
7. PL_AI_POWER = мощность;  PL_AI_PLAN = 1
```

## plan_birdy (A = место)
```
PL_AI_WEAPON = 1;  PL_AI_FACING = 1;  PL_AI_ANGLE = 90
мощность = 300;  если 10·men < 300 (со знаком):  мощность = 10·men
PL_AI_POWER = мощность;  PL_AI_PLAN = 1
```
Случайные числа не берутся.

## record_shot (A = место; fl_x — 4 байта, число с фиксированной точкой 16.16)
```
X = слово по адресу fl_x + 2 (целая часть, со знаком)
если X отрицательное (бит 15 = 1) и слово по адресу fl_x не равно нулю:  X = X + 1     ; усечение к нулю
скопировать 4 байта PL_AI_S1 в PL_AI_S2
PL_AI_S1: мощность = PL_POWER (слово), x = X (слово)
```
Остальные поля записи и записи других игроков не трогать.

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`.
Нельзя писать `sub (метка)`, `cp (метка)` или `ld e,(метка)` — sjasmplus примет это за число. Значение из ячейки бери
так: `ld a,(метка)`, а слово — `ld hl,(метка)`.
Можно: `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`, `ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`,
`inc`/`dec`, `cp`, `sub`, `sbc a`, `add a`, `adc a`, `and`, `or`, `xor`, `cpl`, `push`/`pop`.
`random` и `dt_ptr` портят регистры — все свои значения (место, адрес записи, мощность, счётчики) храни в ячейках
памяти (`db`/`dw`), имена своих меток и ячеек начинай с `ap_`. Ячейки данных размещай ПОСЛЕ метки `aiplan_end`
(ячейка `ap_rebound` там уже есть). Образцы стиля — `v06c/src/aistep.asm`, `v06c/src/action.asm`.
Подсказка для сравнения слов со знаком: готовая подпрограмма `fl_scmp` (flight.asm): вход HL и DE,
выход A = 0 (равны), 1 (HL > DE), 0xFF (HL < DE); портит B.
Подсказка для 10·men: как в `ac_power` (action.asm) — десять сложений `add hl,de`.
