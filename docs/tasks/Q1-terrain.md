# Q1. Рельеф на ассемблере 8080 (маленькая задача)

Нужно написать ОДНУ подпрограмму `gen_terrain` в файле `v06c/src/terrain.asm`. Больше никакие файлы менять нельзя.

## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/terrain.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  рельеф:`. Пока печатает `FAIL ...` — не готово:
в сообщении написан первый несовпавший столбец, высота или RandSeed. После этого ещё запусти
`node v06c/test/run.mjs` — он должен закончиться строкой `OK  сверка с эталоном PROFILE_V06C`.

## Что делает подпрограмма
Вход: регистр A = число игроков n (2, 3 или 4). Выход: таблица `terr_top` (256 байт) и слово `terr_h`.
Это перенос функции `generateTerrain` из `web/tankwars.js` (прочитай её). Для Вектора константы такие:
X0 = 3, X1 = 252, начальная высота Random(200), lo = 20, hi = 185, min = 3, max = 205, m = 50 − 6·(n − 2).

Алгоритм (все числа целые; h, s, d — знаковые 16 бит; x — 16 бит):
```
заполнить terr_top[0..255] значением 0xFF
d = 1 − 2·Random(2)
h = Random(200);  s = 0;  x = 3
пока x < 253:
    если (m + 3 > x) или (252 − m < x):
        col(x, h);  x = x + 1;  продолжить цикл       ; ВНИМАНИЕ: в этой ветке случайные числа не берутся
    a = |s|
    если s == 0:  col(x,h); x++; col(x,h); x++; col(x,h)
    если a == 1:  col(x,h); x++; col(x,h); x++; h = st(h); col(x,h)
    если a == 2:  col(x,h); x++; h = st(h); col(x,h); x++; h = st(h); col(x,h)
    если a == 3:  col(x,h); x++; h = st(h); col(x,h); h = st(h)
    если a == 4:  col(x,h); h = st(h); h = st(h)
    r1 = rnd_hi();  если r1 < 13107:  s = s + d
    r2 = rnd_hi();  если (r2 < 6554) или (|s| > 4):  d = −d       ; rnd_hi вызывается ВСЕГДА, оба раза
    если s > 4: s = 4;   если s < −4: s = −4
    если h <= 20: d = 1
    если h >= 185: d = −1
    если h <= 3: s = 1
    если h >= 205: s = −1
    x = x + 1
terr_h = h

st(h):      если s > 0, вернуть h + 1, иначе вернуть h − 1        ; s берётся текущее
col(x, h):  top = 253 − h;  если x в 0..255 и top < terr_top[x] (сравнение беззнаковое, байты): terr_top[x] = top
```
Порядок действий менять нельзя: от него зависит, какие случайные числа берутся и когда.
x может дойти до 254 — это нормально, такие столбцы тоже записываются.

## Готовые подпрограммы (в `v06c/src/random.asm`, их не менять)
- `random`: вход DE = n, выход HL = Random(n). Портит AF, BC, DE.
- `rnd_hi`: выход HL = число 0..65535. Портит AF, BC, DE. «r < 13107» — это беззнаковое сравнение HL с 13107.

Обе портят регистры, поэтому h, s, d, x, m храни в ячейках памяти (`dw`), а не в регистрах.

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`.
Можно: `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`, `ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`,
`inc`/`dec`, `cp`, `sub`, `add a`, `and`, `or`, `xor`, `cpl`, `push`/`pop`.
Сборка сама проверяет это и печатает `Z80-only 0`, если всё в порядке. Образец стиля — `v06c/src/disc.asm`.

Метки `gen_terrain`, `gen_terrain_end`, `terr_top`, `terr_h` должны остаться с этими именами.
