# Q3. Перетасовка, бонус победителю и сортировка результатов на ассемблере 8080 (маленькая задача)

Нужно написать ТРИ подпрограммы в файле `v06c/src/match.asm`: `shuffle_players`, `winner_bonus`, `results_sort`.
Больше никакие файлы менять нельзя.

## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/match.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  матч:`. Пока печатает `FAIL ...` — не готово:
в сообщении написано, какая подпрограмма, на каком месте и какие поля записи не совпали. После зелёного теста запусти
ещё `node v06c/test/place.mjs`, `node v06c/test/terrain.mjs`, `node v06c/test/run.mjs` — все должны закончиться `OK ...`.

Это перенос функций `shufflePlayers`, `winnerBonus`, `results` из `web/tankwars.js` (прочитай их).

## Данные
- `n_players` — байт, число игроков n (2, 3 или 4).
- `players` — таблица записей, каждая длиной `PL_SIZE` (108) байт. Игрок на месте i (1..n) — запись номер i − 1,
  её адрес `players + (i − 1)·PL_SIZE`. Смещения полей — в `v06c/src/player.inc` (прочитай его):
  `PL_WINS` — слово (победы), `PL_SCORE` — 4 байта со знаком (очки), `PL_MEN` — слово (здоровье).
- «Поменять местами двух игроков» = поменять местами все 108 байт двух записей.

## shuffle_players
```
cnt = Random(20) + 10
повторить cnt раз:
    a = Random(n)
    повторять:  b = Random(n)   пока b == a
    поменять местами записи с номерами a и b        ; номера считаются с 0
```
Порядок вызовов Random менять нельзя.

## winner_bonus (A = место победителя w, 1..n)
```
запись номер w − 1:   победы = победы + 1;   очки = очки + n·1000        ; очки — 32 бита, n·1000 помещается в слово
```

## results_sort (A = auto: 0 или 1)
```
повторить n раз:
    для e от 0 до n − 2:
        если победы[e] < победы[e + 1]:  поменять местами записи e и e + 1          ; сравнение слов со знаком
повторить n раз:
    для e от 0 до n − 2:
        если победы[e] == победы[e + 1] и очки[e] < очки[e + 1]:  поменять местами   ; очки — 32 бита СО ЗНАКОМ
у каждой из n записей:  здоровье (PL_MEN) = 100
если auto == 1:
    повторить 200 раз:  Random(319); Random(199); Random(319); Random(199); Random(16)   ; результаты не нужны, важны сами вызовы
```

## Готовые подпрограммы (их не менять, только вызывать)
- `random` (random.asm): вход DE = n, выход HL = Random(n). Портит AF, BC, DE — поэтому счётчики и номера храни в
  ячейках памяти (`db`/`dw`), а не в регистрах.

Подсказки:
- Адрес записи номер k: начни с `ld hl, players`, затем k раз прибавь `PL_SIZE` (`ld de, PL_SIZE` / `add hl, de`).
- Обмен двух записей: цикл на 108 шагов, два указателя; на 8080 удобно один держать в HL, другой в DE, счётчик в B
  (`ld a,(de)` / `ld c,(hl)` / `ld (hl),a` / `ld a,c` / `ld (de),a` / `inc hl` / `inc de` / `dec b` / `jp nz`).
- Сравнение 32-битных очков со знаком: сначала сравни старшие байты как числа со знаком (удобно: к обоим старшим
  байтам применить `xor 0x80` и сравнить беззнаково), при равенстве — остальные три байта беззнаково, от старшего к
  младшему.

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`.
Нельзя писать `sub (метка)`, `cp (метка)` или `ld e,(метка)` — sjasmplus примет это за число. Значение из ячейки бери
так: `ld a,(метка)`, а слово — `ld hl,(метка)`.
Можно: `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`, `ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`,
`inc`/`dec`, `cp`, `sub`, `sbc a`, `add a`, `adc a`, `and`, `or`, `xor`, `cpl`, `push`/`pop`.
Имена своих меток начинай с `mt_`, чтобы не совпасть с метками других файлов.
Сборка сама проверяет команды и печатает `Z80-only 0`, если всё в порядке. Образцы стиля — `v06c/src/place.asm`,
`v06c/src/terrain.asm`.

Метки `shuffle_players`, `winner_bonus`, `results_sort`, `match_end`, `n_players`, `players` должны остаться с этими
именами; строки `n_players: db 0` и `players: ds ...` в конце файла не трогай.
