# T04. Особое оружие Tank Wars 2.5: Laser, CRI, Sonic Blaster, грязь, наведение

Прочитай `docs/CONTRACTS.md`, `re/NOTES.md` (разделы T02, T03), `docs/spec/ballistics.md`, `docs/spec/explosions.md`,
`docs/spec/terrain.md`, `docs/tasks/T03-report.md` (раздел «Для T04» и «Уроки стенда»), `orig/TankWarsV2.5*/BOMB.DOC`
(описание оружия).

## Цель
Спецификация и эталонная модель на Python для всего оружия, которое не входит в обычный взрыв, и для систем наведения.
Модели должны совпадать с оригиналом **побайтно по VRAM**, по записям игроков и по RandSeed после события —
так же, как в T03.

## Что разобрать (номера оружия с 0, поле игрока +0x17)
| № | оружие | где начать |
|---|---|---|
| 5 | Laser | `2583:140f` — ход вместо полёта (множество `2583:2511`) |
| 6–10 | Chain Reaction Inducer 4/D, 8/ND, 8/D, 20/ND, 20/D | `318e:08ba`; прямое попадание `08da` (множество `318e:0040`); подгруппа {6,8,10} — `0c6b`; использует Circle `1827:11ea` |
| 12 | Sonic Blaster | `318e:0f6f` (по DOC — обрушивает рыхлую землю при Crumble) |
| 13–16 | Ball o Dirt, Mark II, Compressed, Super-Compressed | `318e:10d5`; в полёте отскок от танков `2583:0d71` (×1.2, T02) |
| 17 | Explosive Dirt | `318e:1296` |
| — | наведение Herb's / Vick's | в полёте `2583:06cf` (T02 описал только «где ветвится»); выбор цели `30b8` («Please click on target») |
| — | щиты как предметы | Energy Shield (+0x45) и Inertia Dampener (+0x49) — как покупаются и ставятся (цены DS:2F8C) |

Для каждого: что рисуется (кадры анимации можно не моделировать, если итоговый VRAM совпадает), что меняется в земле,
урон/щиты/очки, расход ГСЧ (в т.ч. на звук, как в T03), особые случаи (край поля, попадание в танк, цепочки CRI).
**Circle:** если CRI рисует через `1827:11ea`, итоговые пиксели нужны точно. Есть два пути — портировать программную
эмуляцию Graph (ядро) или показать, что на итоговый VRAM Circle не влияет (например, затирается). Выбор обосновать.

## Метод
- Стенд — `scripts/t03/gamerun.py` (вся игра в unicorn) и пробы из `scripts/probe/` T03: `boot_to_round`, `run_to`,
  `computer_keys`, шаблон `explosion_fixtures.py` (подмена оружия на входе события, снятие вход/выход).
  Подменять можно только входы (оружие, звук, щиты, цель наведения, параметры выстрела) — дальше исполняется оригинал.
- Учти уроки T03: останов по адресу — только хуком (`Game.run(until=…)` уже так сделан); хук-событие при продолжении
  с того же адреса срабатывает повторно (нужен пропуск первого, см. `crumble_fixtures.py`); ввод во время хода — через
  таблицу DS:3B90, поэтому игроки — компьютеры.
- Для чтения кода — `scripts/t03/disasm16.py` и покрытие блоков `scripts/t03/coverage.py` (читать только исполняемое).
- Модели: `scripts/ref/weapons.py` (можно несколько файлов `scripts/ref/w_*.py`), переиспользуя `explosion.py`,
  `crumble.py`, `tanks.py`, `tprandom.py`. Существующие модели менять только с сохранением зелёных тестов T03.

## Гейт
- Для **каждого** оружия 5, 6–10, 12, 13–16, 17: не меньше 3 событий из настоящей игры, совпадающих побайтно
  (VRAM, поля игроков, RandSeed); хотя бы одно — с прямым попаданием в танк, хотя бы одно — со звуком.
- Наведение: не меньше 4 траекторий с Herb's и Vick's, совпадающих с оригиналом пиксель в пиксель (как в T02).
- `pytest tests/` зелёный целиком, живые тесты (если добавишь) — под переменной `T04_LIVE`.
- Коммиты с префиксом `T04:`, только свои файлы; коммить после каждого закрытого оружия (work/ в git не попадает).
  Если упёрся больше чем на 30 минут — запиши в отчёт («Блокеры») и переходи к следующему оружию.
