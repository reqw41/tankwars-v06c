# Q2. Отрисовка рельефа и расстановка танков на ассемблере 8080 (маленькая задача)

Нужно написать ДВЕ подпрограммы в файле `v06c/src/place.asm`: `render_terrain` и `place_tanks`.
Больше никакие файлы менять нельзя.

## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/place.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  расстановка:`. Пока печатает `FAIL ...` — не
готово: в сообщении написано, что не совпало (танк, RandSeed или первая точка экрана). После зелёного теста запусти
ещё `node v06c/test/terrain.mjs` и `node v06c/test/run.mjs` — оба должны закончиться строкой `OK ...`.

Это перенос функций `renderTerrain` и `placeTanks` из `web/tankwars.js` (прочитай их и функции `drawTank`,
`eraseTank`, `drawTankBarrel`, `drawFrame`, `sup`).

## Экран и координаты
Экран 256×256, точка (x, y), y = 0 сверху. Цвета: 0 фон, 1 земля, 2 рамка, 4..7 танки игроков 1..4.
Поле: X0 = 3, X1 = 252, Y0 = 27, Y1 = 252.

## render_terrain
```
для x от 0 до 255:
    top = terr_top[x]                       ; таблица из gen_terrain (уже заполнена)
    если top != 0xFF и top <= 252:
        поставить точки цвета 1 в столбце x от y = top до y = 252 включительно
```
Проще всего — вертикальной линией: `line` с x1 = x2 = x, y1 = top, y2 = 252, цвет 1.

## place_tanks (A = n, число игроков 2..4)
```
r1 = Random(24);  first = r1 + 8
r2 = Random(24);  last = 248 − r2            ; СНАЧАЛА первый Random, ПОТОМ второй — порядок важен
x[1] = first;  x[n] = last
q = (last − first) / (n − 1), целое деление   ; n − 1 равно 1, 2 или 3; last всегда больше first
для i от 2 до n − 1:  x[i] = (i − 1)·q + first
для i от 1 до n по порядку:
    angle[i] = 75, если i == 1 или i == n; иначе 90
    facing[i] = −1 (байт 0xFF), если i == n; иначе 1
    y[i] = 28
    any = «хотя бы для одного dx из −4..4 выполняется sup(x[i] + dx, y[i])»
    если any ложно:
        повторять:
            стереть корпус танка в (x[i], y[i])        ; erase_tank
            y[i] = y[i] + 1
            нарисовать корпус в (x[i], y[i]) цветом i + 3   ; draw_tank
            all = «для всех dx из −4..4 выполняется sup(x[i] + dx, y[i])»
        пока all ложно
        нарисовать танк со стволом                    ; draw_tank_barrel
        нарисовать рамку                              ; draw_frame, A = pl_rebound
    (если any истинно — танк НЕ рисуется вообще и y[i] остаётся 28; так в оригинале)
записать x, y, angle, facing в таблицы tk_x, tk_y, tk_angle, tk_facing (игрок i — в ячейку i − 1)

sup(x, y):  цвет точки (x, y + 1) равен 1 (земля) или 2 (рамка)
```
Случайные числа берутся только два раза, в самом начале.

## Готовые подпрограммы (их не менять, только вызывать)
Все портят регистры AF, BC, DE, HL — поэтому свои счётчики и координаты храни в ячейках памяти (`db`/`dw`).
- `random` (random.asm): вход DE = n, выход HL = Random(n).
- `getpixel` (pixel.asm): вход D = x, E = y; выход A = цвет точки 0..7.
- `draw_tank` (sprite.asm): вход D = x, E = y, A = цвет. Рисует корпус танка.
- `erase_tank` (sprite.asm): вход D = x, E = y. Стирает корпус (цветом 0).
- `draw_tank_barrel` (barrel.asm): вход в ячейках `tb_x`, `tb_y` (байты), `tb_idx` (байт, номер игрока 1..4),
  `tb_angle` (СЛОВО, угол), `tb_facing` (байт 1 или 0xFF), `tb_alive` (байт, записать 1). Рисует корпус и ствол.
- `draw_frame` (frame.asm): вход A = 0 или 1 (стены отражают). Рисует рамку поля.
- `line` (line.asm): вход в ячейках `ln_x1`, `ln_y1`, `ln_x2`, `ln_y2` (СЛОВА), `ln_c` (байт, цвет).
- `terr_top` (terrain.asm): таблица 256 байт.

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`.
Нельзя писать `sub (метка)` или `ld e,(метка)` — sjasmplus примет это за число. Значение из ячейки бери так:
`ld a,(метка)`, а слово — `ld hl,(метка)`.
Можно: `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`, `ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`,
`inc`/`dec`, `cp`, `sub`, `add a`, `and`, `or`, `xor`, `cpl`, `push`/`pop`.
Сборка сама проверяет это и печатает `Z80-only 0`, если всё в порядке. Образцы стиля — `v06c/src/terrain.asm`,
`v06c/src/disc.asm`.

Метки `render_terrain`, `place_tanks`, `place_end`, `pl_rebound`, `tk_x`, `tk_y`, `tk_angle`, `tk_facing` должны
остаться с этими именами.
