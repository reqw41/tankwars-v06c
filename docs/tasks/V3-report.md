5. Random — `seed = seed·08088405h + 1` (32 бита), результат — старшие 16 бит `mod n`, при `n=0` ноль; сверка с `TPRandom.word`. Линия — те же ветки, что `line()` в `web/tankwars.js` (вертикаль min/max y, обмен концов при cx<0, ymajor только при `bx > cx`). Точка: три плоскости, бит 7 слева, y в младшем байте адреса столбца.

## Гипотезы

- Ориентация y=0 «сверху» совпадает с логическим экраном эталона; с растром ТВ и регистром вертикального скролла Вектора это не сверялось (сравнение идёт по дампу памяти, не по `displayFrame`).
- Константа LCG собрана сложением `seed` со сдвигами на биты 0,2,10,15,19,27; это то же умножение по модулю 2^32, что в JS, но форма записи другая.
- `vcycles` эмулятора больше `cpu_cycles` из‑за растяжек шины Вектора; в таблицу гейта они не входят.
