# T01b. Доработка T01: Graph проверить исполнением, мелкие исправления

Прочитай `docs/CONTRACTS.md`, `re/NOTES.md`, `docs/tasks/T01-rtl-ident.md`, `docs/tasks/T01-report.md`.

## Итог приёмки T01
**Принято:** System (Real48, LongInt, Random) — проверено исполнением, плюс мои краевые прогоны
(`scripts/check/extra.py`); покрытие (`scripts/check/cov_full.py`, полные диапазоны сегментов: 2993 из 2993);
пересборка с нуля совпадает с экспортом (с точностью до записи адресов thunk).

**Не принято:** имена Graph/GraphWrap. Они выведены из первого `MOV SI,xx`, и это не доказательство:
- `1827:1fcc` назван SetFillStyle, но вызывает драйвер с SI=2Eh, снимает 4 байта аргументов (x,y)
  и по смыслу похож на **GetPixel**. Названные GetPixel `1aa7/1ac1/1ade` игра не вызывает вовсе.
- `1827:1f12` (Bar) вызывает драйвер дважды: SI=08h, затем SI=26h. Первый SI не определяет функцию.
- Самые частые цели названы правдоподобно только на вид: `13f2` RegisterBGIdriver — 76 вызовов из игры,
  `1454` RegisterBGIfont — 69, `1131` GraphResult_set — 29, `0f93` SetRGBPalette — 21,
  `1496` SetPalette — 19, `16e3` GetPaletteSize — 14. Регистрация драйвера 76 раз невозможна.
- Одному коду SI=08h присвоены 6 разных имён, есть дубли (GetPixel×3, GetImage×2, SetColor×2, OutTextXY×2).
Список целей с числом вызовов, retf и всеми SI: `scripts/check/graph_game.py`.

## Что сделать
1. **Эмуляция Graph с настоящим драйвером.** Расширь `scripts/emu16.py`: видеопамять A000:0000 64 КБ,
   хук INT 10h (смена режима, палитра — просто записать вызовы в лог), прочие прерывания логировать.
   Инициализацию провести тем же путём, что игра (регистрация вшитого VGA256 + InitGraph, см. главную
   программу `1000:*`), или минимально достаточной последовательностью вызовов Graph, обосновав её.
2. Для **каждой** функции Graph/GraphWrap (175e, 1827), которую вызывает игра (их 47, см. скрипт выше),
   вызвать её с осмысленными аргументами и зафиксировать наблюдаемый эффект: какие пиксели изменились
   (diff видеопамяти), что вернулось, какие вызовы INT 10h/драйвера произошли, какие глобалы DS изменились.
   Имя давать по эффекту. Примеры доказательства: PutPixel(10,20,5) меняет ровно байт A000:20*320+10 на 5;
   GetPixel возвращает записанное; Bar/Rectangle/Line — форма изменённой области.
   Сначала разобраться, что такое 13f2, 1454, 1131, 0f93, 1496, 16e3, 1042, 1fcc, 1f12, 1cce, 1c86.
3. Имена уникальные. Суффиксы `2/3` допустимы только если в evidence сказано, чем функции отличаются.
   Функции, которые игра не вызывает, можно оставить со статическим именем и `verified=static`,
   но без выдуманной семантики: если не уверен — `GRAPH_unk_<addr>`.
4. **System:**
   - LongDiv `1c5b:0a2d` возвращает частное в DX:AX и остаток в CX:BX, округление к нулю. Записать это в CSV,
     добавить тесты с неточным делением (−7 div 2 = −3, остаток −1).
   - В Real-тесты добавить большие значения (1e6, 1e12, 1e30) и Trunc/Round за пределами Integer (±40000, ±70000.5).
5. `scripts/rtl_coverage.py`: границы игровых сегментов брать из `re/ovl_map.txt` (размер кода оверлея),
   для 1000 и 1062 — полный диапазон до следующего сегмента, а не конец последней найденной функции.
