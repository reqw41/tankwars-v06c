## Проверка (единственный критерий готовности)
```
sh v06c/build.sh && node v06c/test/action.mjs
```
Готово, когда вторая команда печатает строку, начинающуюся с `OK  действия:`. Пока печатает `FAIL ...` — не готово:
в сообщении написаны коды и что не совпало (поле записи игрока, точка экрана или ответ needs_switch). После зелёного
теста запусти ещё `node v06c/test/after.mjs`, `node v06c/test/round.mjs`, `node v06c/test/run.mjs` — все должны
закончиться `OK ...`.

Это перенос функций `applyCode`, `autoSwitchWeapon`, `needsWeaponSwitch` из `web/tankwars.js` (прочитай их и
`drawTankBarrel`).

## Данные
Игрок — запись в таблице `players` с местом `ac_place` (1..n): адрес `players + (ac_place − 1)·PL_SIZE`.
Поля (`v06c/src/player.inc`): `PL_X`, `PL_Y` — байты; `PL_ANGLE` — байт 0..90; `PL_FACING` — байт: 1 или 0xFF (это −1);
`PL_POWER` — слово; `PL_MEN` — слово со знаком; `PL_WEAPON` — байт 0..17; `PL_GUIDED` — байт; `PL_HERB`, `PL_VICK` —
слова; `PL_AMMO` — 18 слов со знаком: запас оружия w лежит по смещению `PL_AMMO + 2·w`. Запас оружия 5 — это «энергия».

## apply_code (A = код)
```
код 7 или 8 (сменить оружие):
    повторить не больше 40 раз:
        если код 8: weapon = weapon + 1, иначе weapon = weapon − 1
        если weapon < 0: weapon = 17;   если weapon > 17: weapon = 0
        a = запас[weapon]
        если a > 0 и НЕ (weapon == 5 и a < 100):  закончить

код 1 или 2 (угол):
    стереть ствол                                  ; см. «Как стереть и нарисовать» ниже — ДО изменения угла
    если код 1: angle = angle + facing, иначе angle = angle − facing      ; facing = +1 или −1
    если angle > 90:  facing = −facing;  angle = 180 − angle
    если angle < 0:   facing = −facing;  angle = −angle
    записать angle и facing в запись;  нарисовать танк со стволом

код 3 или 4 (мощность):
    если код 4: power = power + 1, иначе power = power − 1
    если power > 10·men:  power = 10·men           ; сравнение со знаком; men бывает <= 0
    если power < 0:  power = 0
    если weapon == 5 и power > запас[5]:  power = запас[5]

код 6 (разворот):
    стереть ствол;  facing = −facing;  нарисовать танк со стволом

код 9:  если herb > 0:  guided = guided XOR 1
код 10: если vick > 0:  guided = guided XOR 2
прочие коды (в том числе 5): ничего не делать
```
Угол во время вычисления может стать −1 или 91 — считай его в регистре как число со знаком, в запись клади уже
исправленное значение 0..90.

## auto_switch
```
если запас[weapon] != 0:  выйти                    ; именно «не равно нулю»
повторить не больше 40 раз:
    если weapon >= 17: weapon = 0, иначе weapon = weapon + 1
    если запас[weapon] > 0:  закончить
```

## needs_switch → CF
```
CF = 1, если запас[weapon] <= 0  или  (weapon == 5 и запас[5] <= 100);  иначе CF = 0
```
Запасы — слова со знаком: «<= 0» значит ноль или отрицательное.

## Как стереть и нарисовать ствол (готовые подпрограммы из barrel.asm)
Заполни ячейки: `tb_x`, `tb_y` (байты) — из `PL_X`, `PL_Y`; `tb_idx` (байт) — `ac_place`; `tb_angle` (СЛОВО: младший байт
— угол, старший — 0); `tb_facing` (байт) — `PL_FACING`; `tb_alive` (байт) — 1.
- Стереть ствол: `call tb_ends`, затем `xor a` / `ld (ln_c), a` / `call line`. Это линия цвета 0 по стволу.
- Нарисовать танк со стволом: `call draw_tank_barrel`.
Перед стиранием в ячейках должны быть СТАРЫЕ угол и направление, перед рисованием — НОВЫЕ.
Все подпрограммы портят регистры AF, BC, DE, HL — адрес записи и свои значения храни в ячейках памяти (`db`/`dw`).

## Правила ассемблера (важно)
Синтаксис — мнемоники Z80 в sjasmplus, но процессор 8080: разрешены только команды, которые есть у 8080.
Нельзя: `jr`, `djnz`, `ix`, `iy`, `ex af`, `exx`, `ldir`, `bit`/`set`/`res`, `sla`/`sra`/`srl`/`rl`/`rr` (кроме `rla`, `rra`,
`rlca`, `rrca`), `neg`, `sbc hl`, `adc hl`, `ld bc,(nn)`, `ld de,(nn)`, `ld (nn),bc`, `ld (nn),de`.
Нельзя писать `sub (метка)`, `cp (метка)` или `ld e,(метка)` — sjasmplus примет это за число. Значение из ячейки бери
так: `ld a,(метка)`, а слово — `ld hl,(метка)`.
Можно: `ld hl,(nn)`, `ld (nn),hl`, `ld a,(nn)`, `ld (nn),a`, `add hl,de`, `ex de,hl`, `jp`, `jp z/nz/c/nc/m/p`, `call`, `ret`,
`inc`/`dec`, `cp`, `sub`, `sbc a`, `add a`, `adc a`, `and`, `or`, `xor`, `cpl`, `push`/`pop`.
Имена своих меток начинай с `ac_`. Образцы стиля — `v06c/src/round.asm`, `v06c/src/place.asm`.
НЕ пиши свои копии линии и рисования танка — вызывай готовые `line`, `tb_ends`, `draw_tank_barrel`.

Метки `apply_code`, `auto_switch`, `needs_switch`, `action_end`, `ac_place` должны остаться с этими именами. Метка
`action_end` должна стоять сразу после конца твоего кода, перед ячейками данных.
