# Tank Wars 2.5 — обычный взрыв и урон

Процедура `318e:00e0` (стаб `1054:0020`), вызывается из полёта `2583:01c0` после попадания.
Аргументы (Pascal, слева направо): игрок-стрелок, x (Real48 TW_ShotX), y (Real48 TW_ShotY), цвет попадания (DS:3EE4).
Модель: `scripts/ref/explosion.py`; тест `tests/test_explosion.py` — 28 взрывов из настоящей игры, совпадают
VRAM (весь экран), men/щит/очки всех игроков и RandSeed после взрыва.

## 1. Нумерация оружия (поле игрока +0x17, массивы имён DS:0720/1920 начинаются с 0)

| № | оружие | ветка 318e |
|---|---|---|
| 0 | Lead Ball | ни в одном множестве — взрыва нет («useless») |
| 1–4 | Incinerator, Mark II, 20 Kiloton, 5 Megaton | **обычный взрыв**, R = 10/15/30/60 |
| 5 | Laser | ход `2583:140f` (множество `2583:2511`), не полёт |
| 6–10 | CRI 4/D … 20/D | `318e:08ba` (T04); внутри {6,8,10} — `0c6b` |
| 11 | Hand Grenade | обычный взрыв, R = 2 |
| 12 | Sonic Blaster | `318e:0f6f` (T04) |
| 13–16 | шары грязи | `318e:10d5` (T04); в полёте отскок от танков `2583:0d71` (T02) |
| 17 | Explosive Dirt | `318e:1296` (T04) |

## 2. Обычный взрыв (оружие 1,2,3,4,11)

```
R = {1:10, 2:15, 3:30, 4:60, 11:2}[weapon]                      DS:3EDA
SetViewPort(11,31,309,189,clip)                                   координаты ниже — во вьюпорте
cx = Trunc(x - 11);  cy = Trunc(y - 31)
огонь:    for i = 0..R:   ring(cx+1,cy,i,130+i); ring(cx-1,cy,i,130+i); ring(cx,cy,i,130+i)
палитра:  три прохода «перелива» по цветам 130..130+R (только DAC)
воронка:  for i = R..0:   restore(cx+1,cy,i); restore(cx-1,cy,i); restore(cx,cy,i)   — пиксели из буфера фона
прямое попадание (цвет 20..29):  жертва = цвет-19: hit(жертва, 200)
SetViewPort(полный); x,y обратно в экранные
для каждого живого танка p:  d = Hypot(x - p.x, y - p.y)        (Real48: Sqrt(Sqr+Sqr))
    dmg = 0
    if d <= 1.5R:  dmg += Trunc(1.8R - d)
    if d <  R:     dmg += 10 + 2*Trunc(1.8R - d)
    if d <  0.7R:  dmg += 150
    hit(p, dmg)
hit(p, dmg):  p.shield -= dmg                 (Energy Shield, +0x45 LongInt)
              if p.shield < 0:  if p ≠ стрелок: стрелок.score += 10*(-p.shield)   (+0x04 LongInt)
                                p.men += p.shield;  p.shield = 0
```
Константы Real48: 1.5 точно, 1.8 = 1.7999999999992724, 0.7 = 0.6999999999998181.
Расстояние в модели считается в double; на 28 эталонах расхождений с Real48 нет (на границах порогов возможны —
см. гипотезы в отчёте). «Explotions Kill» (DS:8203) в этой ветке не используется.

**Кольцо** `1691:025c` / восстановление `1691:0592` — целочисленный алгоритм средней точки для эллипса (rx=ry=i),
четыре симметричные точки ведутся как смещения VRAM; при выходе эллипса за вьюпорт точки отсекаются по
вьюпорту включительно. Порт побитно: `explosion.ellipse_points`. Три центра со сдвигом ±1 по x закрывают промежутки
между кольцами — воронка без дыр (≈ диск радиуса R, шире на 1 px по горизонтали).

**ГСЧ во взрыве** тратится только на звук (DS:81FF ≠ 0): Random(500) × (R+1), затем Random(500) × T, Random(500) × T,
Random(250) × T, где T = (R+1)(R+2)/2. Без звука взрыв ГСЧ не трогает. Для совместимости сидов это обязательно.

## 3. Circle в настоящей игре (вопрос из T01b закрыт)

`1827:11ea` (Circle) в настоящей игре **рисует** — программная эмуляция ядра Graph (драйвер на SI=14h отдаёт
работу ядру). Наблюдение: во взрыве CRI `Circle(288,65,7)` меняет 40 пикселей, рамка ровно радиуса 7
(`tests/fixtures/t03/circle_real.json`, `tests/test_circle_real.py`). Стенд `graph_env.make_graph_emu` из T01b обходит
InitGraph и подключает другую копию драйвера, поэтому там эллипс рисует хук стенда — тот тест доказывает только
передачу параметров. Обычный взрыв Circle не использует (только `1691:025c/0592`).
