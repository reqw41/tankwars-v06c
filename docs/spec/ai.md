# Tank Wars 2.5 — компьютерные игроки

Модель: `scripts/ref/ai.py`. Тесты: `tests/test_ai.py` (84 хода: план, RandSeed, первый код; 84 цикла кодов до огня).
Эталоны: `tests/fixtures/t05/ai/*` (проба `scripts/probe/ai_fixtures.py`, игра не подменяется; для Twanger принудительно
включены отражающие стены, для Birdy Bonker подменено имя игрока).

## Доказано

### Кто есть кто
Тип управления игрока — слово `DS:8880+2*i`: 1 клавиатура, 2 мышь, 3 компьютер. Тип ИИ определяется **по имени**
игрока при каждом вызове `2cab:000d` (стаб `1049:0020`); имена — `DS:0020+0x100*k`:

| имя | тип | поведение |
|---|---|---|
| Mr. Stupid | 1 | случайный угол и мощность |
| Birdy Bonker | 2 | скрытый: в списке имён его нет; всегда вверх, мощность 300 |
| Rifleman | 3 | прямая наводка |
| Lobber | 4 | навес 75°, мощность по двум последним выстрелам |
| Lob & Shoot | 5 | без отражающих стен = Lobber (4), со стенами = Rifleman (3) |
| Windless Wit | 6 | точное решение параболы без учёта ветра |
| Twanger | 7 | рикошет от потолка; без отражающих стен = Rifleman (3) |

Имя «Random» (`DS:0020`) при создании игрока заменяется на одно из шести: `Random(6)+1` (экран игроков `32ec:37b8`).

### Структура ИИ — `DS:8896 + 0x802*i` (есть у каждого игрока, обнуляется в `32ec:0139`)
| смещение | поле |
|---|---|
| +0 | счётчик истории n: 0 при расстановке в начале раунда (`2eef:0909`), +1 в начале каждого хода (`2583:27b9`) |
| +2 | байт «план готов» |
| +3, +5, +7, +9 | план: мощность, угол, направление (±1), оружие |
| +0x0B+10k | выстрел k: угол, мощность, направление, x, y точки остановки снаряда (`2583:29ee`) |
| +0x7E6 | цель (номер игрока); её же берёт наведение у компьютера (`30b8:08a1`) |
| +0x7E8, +0x7EA | dx, dy до цели |
| +0x7EA+2k | оценка игрока k (k = 1..10) |
| +0x800 | стратегия закупки 1..4 (см. `match.md`) |

### Цикл хода компьютера (`2b39:0f78` → `2cab:000d`)
Функция ввода вызывается в цикле и возвращает один код «нажатия»; у человека это клавиша, у компьютера — шаг к плану:

`1`/`2` угол +/− в сторону направления, `3`/`4` мощность −1/+1, `5` огонь, `6` разворот, `7`/`8` оружие назад/вперёд
(у человека ещё `9`/`10` — включить наведение Herb/Vick).

Если у текущего оружия нет патронов (или это лазер с запасом ≤ 100) — сразу код 8, ИИ не вызывается.
Иначе, если план не готов, работает планировщик типа; затем `choose_code` (`2cab:213e`):

```
пока ammo[план.оружие] < 1: план.оружие -= 1 (ниже 0 -> 12)
план.мощность = min(план.мощность, 10*men); для лазера ещё min(.., энергия); не меньше 0
код = 5
t = Trunc((facing-1)/2)                      # 0 вправо, -1 влево
угол < план: код = 1 - t;  угол > план: код = t + 2
мощность > план: 3;  < план: 4
направление != план: 6;  оружие != план: 8          # приоритет растёт сверху вниз
код 3 и разница > 99: мощность -= 90;  > 9: ещё -= 9   (код 4 — зеркально)   # ускорение
код 5: «план готов» = 0
```

Применение кода (`2b39:0577..0efe`) — общее с человеком: коды 7/8 листают оружие, пропуская пустое (и лазер с запасом
< 100); 1/2 стирают и рисуют ствол, при угле > 90 или < 0 переворачивают танк; 3/4 ограничивают мощность 0..10·men
(для лазера — энергией).

### Планировщики
Общее: `первое оружие` = 11 (Hand Grenade), затем последнее из 1..4, у которого есть патроны.

**Mr. Stupid (1).** направление = `Random(3)-1`, пока не ±1; первое оружие; угол = `Random(90)`; мощность =
`Random(5000)+20`. Без отражающих стен: направление = −1, если номер игрока > N div 2, иначе +1; мощность =
`Random(250)+50`. Мощность ≤ 10·men.

**Birdy Bonker (2).** оружие 1, направление +1, угол 90, мощность 300 (≤ 10·men).

**Windless Wit (6)** (`2cab:014c`). Цель = `Random(N)+1`, пока не «другой живой». dx = x_ц − x, dy = y_ц − y;
если dy < 0: dy += 4; если dx > 0: dx −= 4; если (после этого) dx < 0: dx += 4.
vx = ±(`Random(100)+50`)/50 (знак «+», если номер цели больше своего); t = dx/vx; vy = (dy − 0.05·t²)/t;
мощность = Trunc(Hypot(50·vy, 50·vx)); угол = |Trunc(RadToDeg(ArcTan(vy/vx)))|; направление по номеру цели;
первое оружие. На экране при этом мигает сжимающийся круг на цели (экран восстанавливается).

**Rifleman (3)** (`2cab:0662`). Оружие 1 (11, если Incinerator кончился). Для каждого игрока k оценка: 1000; если цель
ниже стрелка (y_k > y) — 100; сам и мёртвые — 0. Если оценка > 0, от стрелка к k идёт луч по пикселям
(шаг 1 по Hypot): каждый пиксель цвета 2 (земля) −1; пиксели луча закрашиваются цветом k+19 **на экране** (поэтому более
поздние лучи видят более ранние), в конце экран восстанавливается из копии. Цель — первая с наибольшей оценкой.
dx = x_ц − x, dy = y − y_ц + 4 (ноль → 1). Если оценка > 990: оружие 2/3/4 при Hypot(dx,dy) > 15/30/60 и наличии
патронов. Если оценка ≤ 990 и энергии лазера > 100: оружие 5. Мощность 1000; угол = |Trunc(RadToDeg(ArcTan(dy/dx)))|;
направление по номеру цели. Если dy < 0 (цель ниже): со стенами угол = `Random(70)+10`; без стен мощность =
`Random(100)+200`, угол 45; оружие 1.

**Lobber (4)** (`2cab:1b0b`). Оружие 1 (11). Если направление плана не ±1 → 1. d = направление; `Random` тратится
всегда; если n = 1 и Random ≤ 0.5: d = −d. Если n < 3: цель = свой номер + d по кругу 1..N, пока не «другой живой».
Иначе цель = живой k ≠ себя с наименьшим |x последнего выстрела − x_k|. Если цель оказалась по другую сторону, чем
направление плана, n = 1 (история сброшена). Направление = по номеру цели.
n = 1: угол 75, мощность `Random(100)+100`. n = 2: угол 75, мощность `Random(100)+200`.
n > 2: по выстрелам i = n−2 и j = n−1: k = (P_j − P_i)/(X_j − X_i) (нулевые разности → 1);
промах = x_ц − X_i; мощность = P_i + Trunc(промах·k) mod 32767; отрицательная → ×(−2).
Оружие 2/3/4 при |промах| > 5/15/30, затем понижение 4→3→2→1→11→0, пока нет патронов. Угол не меняется.
(Двойной цикл по всем парам выстрелов в оригинале перезаписывает результат — значима только последняя пара.)

**Twanger (7)** (`2cab:0e01`, только со стенами). «Потолок» y = 28. Для цели k: top = y_k − 28;
a = ArcTan(|(y − y_k + 2·top)/(x_k − x)|); вверх = y − 28; сдвиг = Trunc(±вверх/tan a). Два луча: от танка к точке
потолка (земля −3 за пиксель) и от неё к цели (−1); лучи рисуются прямо в видеопамять (`1691:0ac1`).
Оценки: 1000, сам и мёртвые −1. Ранжирование: среди игроков с наибольшей оценкой выбирается ближайший
(1000 − Trunc(Hypot)). Для него экран восстанавливается, оценка считается заново. Мощность = `Random(51)+950`;
угол = |Trunc(RadToDeg(a))|; оружие 1; если оценка > 990 — 2/3/4 при расстоянии > 15/30/60; иначе лазер при
энергии > 100.
