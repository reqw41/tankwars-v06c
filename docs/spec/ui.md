# Tank Wars 2.5 — управление, панель, звук

Разобрано по декомпиляции и ассемблеру (`re/export/decomp.c`, `work/pturn.asm`, `work/keys.asm`); эталонов исполнения
для этого раздела нет — кроме кодов действий, которые проверены на ходах компьютера (`tests/test_ai.py`).
Раскладка экрана 320×200 для Вектора (256×256) всё равно будет другой, поэтому здесь — содержание, а не пиксели.

## Доказано (статикой)

### Ввод хода — `2b39:0f78(игрок, тип управления)` возвращает код действия
| код | действие (`2b39:0425`) |
|---|---|
| 1 / 2 | угол: +направление / −направление (переход через 90° и 0° разворачивает танк) |
| 3 / 4 | мощность −1 / +1 (0..10·men; у лазера — не больше энергии) |
| 5 | огонь |
| 6 | разворот |
| 7 / 8 | предыдущее / следующее оружие (пустое пропускается) |
| 9 / 10 | включить-выключить наведение Herb / Vick (бит 0 / бит 1 слова +0x19), если есть запас |

Клавиатура через BIOS (`DS:81F1` = 0): ← 1, → 2, ↓ 3, ↑ 4, PgUp: мощность +99 и код 4 (итого +100), PgDn: −99 и код 3,
Tab 8, Shift-Tab 7, пробел или Enter 5, `I` 6, `H` 9, `V` 10, цифры `1`..`0` — окно сведений об игроке 1..10
(`30b8:0040`: имя, запасы; экран сохраняется и восстанавливается). Скан-коды стрелок — таблица `DS:33B4`
(`H P M K I Q G O`).

Свой обработчик клавиатуры (`DS:81F1` = 1): таблица «клавиша нажата» `DS:3B90+скан-код` (расширенные — `+0x100`);
те же действия с автоповтором по удержанию; при зажатом Alt (скан 0x38) — один шаг на нажатие. После каждого опроса —
`CRT_Delay(DS:8862)` (ключ `SPEED`).

Мышь (тип 2): щелчок по танку (цвет пикселя 20..29) — окно сведений; зоны панели: название оружия (y 18..27) — левая
кнопка 7, правая 8; зоны Herb и Vick — 9 и 10; поле угла (x 56..70, y 0..7) — левая 1, правая 2; поле мощности
(x 56..86, y 10..17) — левая 3, правая 4.

Если у текущего оружия нет патронов (или лазер с запасом ≤ 100) — код 8 без опроса.

### Выбор цели наведения — `30b8:08a1`, после огня, если включено наведение
Клавиатура: → / ← листают живых игроков, кроме себя; подтверждение клавишей из множества `30b8:086a`.
Мышь: щелчок по танку. Компьютер: цель = поле +0x7E6 структуры ИИ (на практике компьютер наведение не включает —
кодов 9/10 его планировщики не выдают).

### Панель
`2eef:10dd` рисует ряд из 18 значков оружия 11×15, каждый — своим индексом палитры 100+w (значок «гаснет» палитрой,
когда оружия нет или оно не по карману в магазине: `1691:0b6c(100+w, 63|0, 0, 0)`). Значки заданы вызовами
Line/Bar/Circle/PutPixel — координаты в `re/export/decomp.c`, функция `2eef:10dd`. Индикаторы наведения — индексы
палитры 0x76 (Herb) и 0x77 (Vick): чёрный — нет запаса, белый — есть, синий — включено (`2b39:0425`, коды 9/10).

### Звук — PC Speaker (`CRT_Sound(Гц)`, `CRT_Delay(мс)`, `CRT_NoSound`), только при `DS:81FF` = 1
| где | частоты |
|---|---|
| ход, угол (`2b39:0425`) | код 1 — 1750 Гц, код 2 — 2000 Гц, 10 мс |
| ход, мощность | код 3 — 1500 Гц, код 4 — 2500 Гц, 10 мс; лазер упёрся в энергию — 1500 и 2500 по 10 мс |
| ход, разворот (код 6) | 1750, 2000, 1500, 1250 Гц по 5 мс |
| выстрел (`2583:01c0`, `2583:140f`) | гамма 111, 222, 333, 444, 555, 666, 777, 888, 999, 1111, 1333, 1777, 2111 Гц |
| полёт | `600 − …` (зависит от высоты снаряда) |
| лазер | `50·шаг` |
| взрыв (`318e:00e0`) | `Random(500)` на каждом кольце огня, `Random(250)` на затухании (см. `explosions.md`) |
| CRI, грязь, Sonic | `100·i + …`, `3000 + …`, `3500 + …`, `500 + …`, `250 + …` (`318e:00e0`) |
| гибель (`285c:*`) | `Random(500)`, `Random(2500)`, `Random(1300 − 40·i)`, `Random(200)`; `100·i + 2000` |

Важно для порта: при включённом звуке эффекты тратят ГСЧ (`Random(n)` для частоты), при выключенном — нет. Поэтому
последовательность случайных чисел зависит от настройки звука; эталоны сняты в обоих режимах (поле `sound` в фикстурах).

## Гипотезы / не проверено
- Состав верхней панели (имя, угол, мощность, оружие, ветер), точные тексты и координаты панели, окна сведений,
  заставки и меню настроек (`32ec:*`) не снимались.
- Заставка и экран настроек не разобраны: для порта их придётся делать заново под 256×256.
- Формулы частот «полёт», «CRI/грязь/Sonic» выписаны не полностью (в таблице — вид выражения из декомпиляции).
